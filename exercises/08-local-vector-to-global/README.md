# 8. Перевод вектора из системы стрелки в систему часов

Представим часы с прозрачным вращающимся диском вместо секундной стрелки.

- система координат часов — глобальная;
- система координат диска — локальная;
- начала обеих систем совпадают в центре часов;
- локальная система вращается относительно глобальной.

Представим вектор, неподвижно связанный с диском. Его локальные координаты не меняются при вращении диска, но глобальные координаты изменяются вместе с направлением локальных осей.

Пусть `localVector = (a, b, c)`, а локальные оси выражены в глобальных координатах как `X`, `Y`, `Z`. Тогда:

```text
globalVector = aX + bY + cZ
```

Компоненты локального вектора показывают, сколько раз нужно взять каждый базисный вектор.

## Задание

Реализуйте `localVectorToGlobal(...)` без `Matrix3` и `Matrix4`:

```ts
localVectorToGlobal(
  localVector,
  localXAxisInGlobal,
  localYAxisInGlobal,
  localZAxisInGlobal,
);
```

Верните новый вектор и не изменяйте аргументы.
