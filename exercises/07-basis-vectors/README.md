# 7. Базисные векторы

Положительные направления осей задаются единичными базисными векторами:

\[
X=(1,0,0),\quad Y=(0,1,0),\quad Z=(0,0,1)
\]

Они имеют длину `1`, взаимно перпендикулярны и вместе образуют стандартный базис.

Координаты вектора являются коэффициентами при базисных векторах:

\[
(2,3,4)=2X+3Y+4Z
\]

## От строк к столбцам

Векторы часто печатают горизонтально как строки. Если транспонировать каждую такую запись, получатся векторы-столбцы:

\[
X=\begin{bmatrix}1\\0\\0\end{bmatrix},\quad
Y=\begin{bmatrix}0\\1\\0\end{bmatrix},\quad
Z=\begin{bmatrix}0\\0\\1\end{bmatrix}
\]

Если поставить их рядом, базис окажется записанным по столбцам:

\[
\begin{bmatrix}|&|&|\\X&Y&Z\\|&|&|\end{bmatrix}
=
\begin{bmatrix}1&0&0\\0&1&0\\0&0&1\end{bmatrix}
\]

Для стандартного базиса получается симметричная единичная таблица, поэтому эффект транспонирования визуально незаметен. Он станет очевиднее на повёрнутом базисе.
