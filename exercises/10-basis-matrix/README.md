# 10. Запись базиса в Matrix3

Три базисных вектора можно хранить в специальной таблице — матрице `3 × 3`.

Базис записывается в столбцы:

```text
    [ X.x  Y.x  Z.x ]
M = [ X.y  Y.y  Z.y ]
    [ X.z  Y.z  Z.z ]
```

Можно представить, что три вектора-столбца просто поставили рядом.

Для базиса, повёрнутого на 90° по часовой стрелке:

```text
X = (0, -1, 0)
Y = (1,  0, 0)
Z = (0,  0, 1)

    [  0  1  0 ]
M = [ -1  0  0 ]
    [  0  0  1 ]
```

`Matrix3.set()` принимает аргументы по строкам, поэтому базис записывается так:

```ts
matrix.set(
  X.x, Y.x, Z.x,
  X.y, Y.y, Z.y,
  X.z, Y.z, Z.z,
);
```

Внутренний массив `elements` хранится в column-major порядке.
