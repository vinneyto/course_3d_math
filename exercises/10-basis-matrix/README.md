# 10. Запись базиса в Matrix3

Три базисных вектора можно хранить в специальной таблице — матрице `3 × 3`.

Базис записывается в столбцы:

\[
M=
\begin{bmatrix}
X_x&Y_x&Z_x\\
X_y&Y_y&Z_y\\
X_z&Y_z&Z_z
\end{bmatrix}
\]

Можно представить, что три вектора-столбца поставили рядом:

\[
M=\begin{bmatrix}|&|&|\\X&Y&Z\\|&|&|\end{bmatrix}
\]

Для стандартного базиса получается единичная матрица. Для базиса, повёрнутого на 90° по часовой стрелке:

\[
X=(0,-1,0),\quad Y=(1,0,0),\quad Z=(0,0,1)
\]

\[
M=\begin{bmatrix}0&1&0\\-1&0&0\\0&0&1\end{bmatrix}
\]

`Matrix3.set()` принимает аргументы по строкам, поэтому базис записывается так:

```ts
matrix.set(
  X.x, Y.x, Z.x,
  X.y, Y.y, Z.y,
  X.z, Y.z, Z.z,
);
```

Внутренний массив `elements` хранится в column-major порядке.
