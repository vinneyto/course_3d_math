# 17. Matrix4: преобразование точек и векторов

До сих пор мы хранили базисные векторы в `Matrix3`. Такая матрица умеет
поворачивать и масштабировать векторы, но не умеет хранить смещение.

После введения однородных координат мы можем перейти к матрице `4 × 4`. В
Three.js её представляет класс `Matrix4`.

## Базис и положение локального начала

Обычную матрицу перехода из локальной системы координат в глобальную можно
представить так:

```text
                      [ X.x  Y.x  Z.x  T.x ]
localToGlobalMatrix = [ X.y  Y.y  Z.y  T.y ]
                      [ X.z  Y.z  Z.z  T.z ]
                      [  0    0    0    1  ]
```

Первые три столбца уже знакомы нам по `Matrix3`:

- `X` — локальный базисный вектор X в глобальных координатах;
- `Y` — локальный базисный вектор Y в глобальных координатах;
- `Z` — локальный базисный вектор Z в глобальных координатах.

Четвёртый столбец `T` содержит положение начала локальной системы координат в
глобальных координатах.

Последняя строка `(0, 0, 0, 1)` позволяет использовать однородные координаты.
В этом упражнении мы рассматриваем только такие матрицы. Более общие
проективные матрицы могут иметь другую последнюю строку.

## Локальная точка в глобальных координатах

Пусть локальная точка имеет координаты `(x, y, z)`. Её глобальная координата
вычисляется так:

```text
globalPoint = x * X + y * Y + z * Z + T
```

Или короче:

```text
globalPoint = basis * localPoint + translation
```

Сначала локальные координаты точки раскладываются по базисным векторам. Затем
к результату прибавляется глобальная координата локального начала `T`.

Например, после поворота на 90 градусов против часовой стрелки вокруг Z:

```text
localPoint   = (2, 0, 0)
rotatedPoint = (0, 2, 0)
translation  = (4, 1, 0)
globalPoint  = (0, 2, 0) + (4, 1, 0)
globalPoint  = (4, 3, 0)
```

## Важно: в каких координатах записано смещение

В матрице выше столбец `T` записан в глобальных координатах. Он не означает
«пройти `T.x` вдоль повёрнутого X и `T.y` вдоль повёрнутого Y».

Значение:

```text
T = (4, 1, 0)
```

означает, что начало локальной системы находится в глобальной точке
`(4, 1, 0)`.

Поэтому преобразование удобно мысленно разделить на два этапа:

1. Повернуть точку вместе с локальным базисом вокруг начала координат.
2. Сместить результат на `T` в глобальном пространстве.

## Порядок преобразований

Обозначим матрицу вращения как `R`, а матрицу глобального смещения как `T`.
Стандартная матрица объекта в Three.js содержит произведение:

```text
M = T * R
```

При использовании векторов-столбцов матрицы применяются справа налево:

```text
globalPoint = M * localPoint
globalPoint = T * R * localPoint
```

## Почему запись читается справа налево

Локальная точка стоит в выражении справа. Поэтому первой с ней умножается
ближайшая к ней матрица `R`:

```text
rotatedPoint = R * localPoint
```

Затем матрица `T` применяется уже к результату вращения:

```text
globalPoint = T * rotatedPoint
globalPoint = T * (R * localPoint)
```

Поэтому выражение:

```text
T * R * localPoint
```

нужно читать начиная с `localPoint` и двигаясь влево:

```text
localPoint → rotation R → translation T → globalPoint
```

Это не особенность названий `T` и `R`, а следствие соглашения о
векторах-столбцах: вектор записан справа от матриц, а матрицы действуют на него
слева.

Следовательно, сначала точка поворачивается, а затем смещается в глобальном
пространстве.

Не следует читать запись `T * R` слева направо как список действий. Она
описывает вложенное применение `T * (R * localPoint)`.

Если записать произведение наоборот:

```text
M = R * T
```

то сначала выполнится смещение, а затем весь результат вместе с вектором
смещения повернётся вокруг начала координат. Это другое преобразование.

## Почему смещение действует на точку

Запишем точку в однородных координатах:

```text
point = (x, y, z, 1)
```

При умножении на `Matrix4` получаем:

```text
[ B  T ] [ p ]   [ B * p + T ]
[ 0  1 ] [ 1 ] = [     1     ]
```

Здесь `B` — матрица базиса `3 × 3`, `T` — столбец смещения, а
`p = (x, y, z)` — локальная точка.

Поскольку `w = 1`, четвёртый столбец матрицы участвует в результате.

Для точки в локальном начале:

```text
localOrigin  = (0, 0, 0, 1)
globalOrigin = (T.x, T.y, T.z, 1)
```

Вращение не меняет положение точки `(0, 0, 0)`, но смещение переносит её в
глобальную точку `T`.

## Почему смещение не действует на вектор

Для вектора используем `w = 0`:

```text
vector = (x, y, z, 0)
```

Теперь вклад четвёртого столбца умножается на ноль:

```text
globalVector = basis * localVector
```

Вектор поворачивается и масштабируется вместе с базисом, но не смещается.
Направление не имеет собственного положения в пространстве, поэтому перенос
начала координат не должен на него влиять.

## Как это связано с Object3D

Локальная матрица объекта Three.js обычно строится из свойств `scale`,
`rotation` и `position` в таком порядке:

```text
M = T(position) * R(rotation) * S(scale)
```

Для точки это означает:

1. применить масштаб;
2. применить вращение;
3. применить смещение `position`.

`position` задаётся в координатах родительского объекта. Для объекта без
трансформированного родителя эти координаты совпадают с глобальными.

## Задание

Реализуйте две функции.

### Создание матрицы

`createLocalToGlobalMatrix(rotationRadians, translation)` должна создать новую
`Matrix4`, которая:

1. поворачивает значение вокруг оси Z на `rotationRadians`;
2. затем смещает точку на `translation`.

Получившаяся матрица должна соответствовать порядку:

```text
M = T * R
```

Угол передаётся в радианах — это явно отражено в имени параметра.

### Преобразование однородного значения

`localToGlobal(value, matrix)` должна применить `Matrix4` к `Vector4`.

Для значения с `w = 1` матрица должна применить и вращение, и смещение. Для
значения с `w = 0` смещение должно исчезнуть.

Обе функции должны возвращать новые объекты и не изменять переданные значения.
