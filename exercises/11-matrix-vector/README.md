# 11. Умножение матрицы на вектор

В отрыве от применения матрицы могут выглядеть как игра с таблицами чисел. Но в 3D-графике они формализуют преобразования векторов и систем координат.

Математически вектор можно представить как таблицу с одним столбцом:

```text
    [ x ]
v = [ y ]
    [ z ]
```

У такого представления три строки и один столбец. Поэтому трёхмерный вектор
можно считать частным случаем матрицы размером `3 × 1`.

Матрица умножается на вектор по правилу «строка на столбец»:

```text
[ 1  2  0 ]   [ 3 ]   [ 1*3 + 2*4 + 0*5 ]   [ 11 ]
[ 0  1  0 ] * [ 4 ] = [ 0*3 + 1*4 + 0*5 ] = [  4 ]
[ 0  0  1 ]   [ 5 ]   [ 0*3 + 0*4 + 1*5 ]   [  5 ]
```

## Связь с localVectorToGlobal()

В предыдущих упражнениях мы записали базисные векторы `X`, `Y`, `Z` в столбцы
матрицы `3 × 3`:

```text
    [ X.x  Y.x  Z.x ]
M = [ X.y  Y.y  Z.y ]
    [ X.z  Y.z  Z.z ]
```

Если умножить такую матрицу на локальный вектор `(a, b, c)`, получится:

```text
M * localVector = aX + bY + cZ
```

Каждая компонента локального вектора показывает, сколько раз нужно взять
соответствующий столбец матрицы. Это в точности та же операция, которую в
упражнении 8 выполняла функция `localVectorToGlobal()`:

```text
globalVector = localVectorToGlobal(localVector, X, Y, Z)
globalVector = basisMatrix * localVector
```

Таким образом, умножение матрицы базиса на локальный вектор — это матричная
запись уже знакомого преобразования из локальной системы координат в глобальную.

В Three.js операция записывается так:

```ts
const result = vector.clone().applyMatrix3(matrix);
```
