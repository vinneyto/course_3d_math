# 19. Схлопывание вложенных преобразований

В предыдущем упражнении мы применяли к локальной точке длинную цепочку
преобразований:

```text
localPoint
→ rotation1
→ translation1
→ rotation2
→ scale
→ translation2
→ globalPoint
```

Теперь посмотрим на эту цепочку как на несколько вложенных систем координат.

## Матрица как переход между системами координат

Каждая `Matrix4` в цепочке задаёт переход из одной системы координат в
следующую. Например, `rotation1` переводит точку из самой глубокой локальной
системы в её родительскую систему, следующая матрица переводит результат ещё
на один уровень выше и так далее.

Самая верхняя система координат в этой цепочке — глобальная:

```text
localPoint
  --R1--> coordinateSystem1
  --T1--> coordinateSystem2
  --R2--> coordinateSystem3
  --S ---> coordinateSystem4
  --T2--> globalPoint
```

Раньше наша иерархия состояла только из локальной и глобальной систем. Теперь
между ними появилось несколько промежуточных уровней.

Напомним из [упражнения 17](../17-transform-points-vectors/README.md): первые
три столбца аффинной `Matrix4` содержат повёрнутые и масштабированные базисные
векторы, а четвёртый — положение локального начала в родительской системе
координат.

Матрица чистого вращения меняет только ориентацию базиса. Матрица масштаба
меняет длины базисных векторов. Матрица смещения оставляет базисные векторы
прежними, но переносит начало системы координат.

## Последовательное применение

Точку можно провести через все уровни по очереди:

```text
p1          = R1 * localPoint
p2          = T1 * p1
p3          = R2 * p2
p4          = S  * p3
globalPoint = T2 * p4
```

После подстановки промежуточных результатов получаем:

```text
globalPoint = T2 * S * R2 * T1 * R1 * localPoint
```

Как и раньше, точка записана справа, поэтому ближайшая к ней матрица `R1`
применяется первой.

## Схлопывание матриц

Матричное умножение ассоциативно. Можно заранее перемножить матрицы, не меняя
их порядок:

```text
M = T2 * S * R2 * T1 * R1
```

Тогда вся иерархия применяется к точке одним умножением:

```text
globalPoint = M * localPoint
```

Такое объединение нескольких преобразований в одно называется **композицией
преобразований**. В этом упражнении мы также будем использовать наглядное слово
«схлопывание».

Важно: ассоциативность позволяет менять скобки, но не порядок множителей.
Матричное умножение по-прежнему некоммутативно.

## Хронологический порядок и premultiply

В задании матрицы передаются в хронологическом порядке применения:

```text
[R1, T1, R2, S, T2]
```

Чтобы схлопнуть их в одну матрицу, будем начинать с единичной матрицы и
добавлять каждое следующее преобразование слева:

```text
M0 = I
M1 = R1 * M0
M2 = T1 * M1
M3 = R2 * M2
M4 = S  * M3
M5 = T2 * M4
```

В Three.js такую операцию выполняет метод `premultiply()`:

```text
matrix.premultiply(transform)
matrix = transform * matrix
```

Мы используем `premultiply()` именно для того, чтобы схлопывать матрицы,
проходя исходный список слева направо — в хронологическом порядке действий.
Каждая следующая матрица при этом добавляется слева к уже накопленному
произведению.

В результате получится нужное произведение:

```text
M5 = T2 * S * R2 * T1 * R1
```

## Как это связано с Object3D

У `Object3D` есть свойства `position`, `rotation` и `scale`. Three.js объединяет
их в локальную матрицу `Object3D.matrix`:

```text
object.matrix = T(position) * R(rotation) * S(scale)
```

Эта матрица описывает положение начала объекта и его повёрнутые и
масштабированные базисные векторы в координатах родительского объекта. То есть
несколько отдельных характеристик объекта уже схлопнуты в одно преобразование.

Обычно Three.js обновляет `object.matrix` автоматически. Вручную это можно
сделать вызовом:

```ts
object.updateMatrix();
```

## Численный пример

Используем ту же цепочку, что и в предыдущем упражнении:

```text
localPoint = (2, 1, 1, 1)

R1 = rotation Z на  90°
T1 = translation (3, 0, 0)
R2 = rotation Y на  90°
S  = scale       (1.5, 0.75, 1)
T2 = translation (-1, 2, 4)
```

И последовательное применение, и одна схлопнутая матрица должны дать один
результат:

```text
globalPoint = (0.5, 3.5, 2, 1)
```

## Задание

Реализуйте две функции.

### Последовательное применение

`applyTransformsSeparately(value, transforms)` должна:

1. создать копию `value`;
2. применить к ней все матрицы из `transforms` по очереди, слева направо;
3. вернуть результат.

Массив содержит матрицы в хронологическом порядке действий.

### Схлопывание преобразований

`collapseTransforms(transforms)` должна вернуть одну новую `Matrix4`,
эквивалентную последовательному применению всех матриц.

Начните с единичной матрицы и используйте `premultiply()`, чтобы добавлять
каждое следующее преобразование слева.

Обе функции не должны изменять переданный вектор, массив или матрицы внутри
массива. Для пустого массива `collapseTransforms()` должна вернуть единичную
матрицу.
