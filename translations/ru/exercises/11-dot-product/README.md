# 11. Скалярное произведение

**Скалярное произведение** двух векторов — **скаляр**, то есть одно число, а не стрелка.

```text
a · b = ax*bx + ay*by + az*bz = |a| |b| cos(θ)
a · b = b · a
```

Оно **коммутативно**: перестановка множителей не меняет результат. Для ненулевых векторов знак описывает угол: положительный — острый угол, ноль — 90°, отрицательный — тупой угол.

Векторы **коллинеарны**, если направлены вдоль одной прямой, в том числе в противоположные стороны. Для **нормализованных** векторов скалярное произведение равно `cos(θ)` и лежит в `[−1, 1]`:

- `+1`: одинаковое направление;
- `0`: перпендикулярность (ортогональность);
- `−1`: противоположные направления.

И `+1`, и `−1` означают коллинеарность. Сходство направлений различает эти случаи; модуль результата оценивает близость к коллинеарности без учёта знака.

Для ненормализованных входов важны также длины: `(2, 0, 0) · (3, 0, 0) = 6`, а для нормализованных версий результат равен `1`. Поэтому само скалярное произведение не является независимой от длин мерой сходства направлений. Для сравнения направлений делим его на `|a| |b|` или сначала нормализуем оба входа.

Скалярное произведение нулевого вектора с любым вектором равно нулю, но у нулевого вектора **нет направления**. Косинусное сходство для него не определено; нулевой результат в этом случае не описывает угол 90°.
