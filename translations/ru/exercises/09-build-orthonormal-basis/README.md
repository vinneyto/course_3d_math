# 9. Построение ортонормированного базиса

Два непараллельных вектора позволяют построить три взаимно перпендикулярных направления. Возьмём `a = (2, 0, 0)` и `b = (1, 2, 0)`: они не ортогональны.

```text
x = normalize(a)
z = normalize(x × normalize(b))
y = z × x
```

Первое векторное произведение даёт направление, перпендикулярное обоим исходным векторам. Второе даёт направление, перпендикулярное `z` и `x` и лежащее в исходной плоскости. Направление `a` сохраняется, а **направление b в общем случае заменяется**.

Три ненулевых взаимно перпендикулярных вектора образуют **ортогональный базис**. Если длина каждого равна `1`, базис **ортонормированный**. В примере получаем стандартный базис X, Y, Z. Вместе с выбранным началом координат эти оси задают систему координат.

Порядок важен: `z × x` даёт `y`, а `x × z` даёт `−y`. Мы строим **правый** базис: `x × y = z`. Это соглашение о направлениях, а не дополнительная нормализация.

Нулевые или параллельные входные векторы не задают такой базис: нет однозначно определённой плоскости для вычисления `z`. Почти параллельные векторы также приводят к численной неустойчивости. Сначала нормализуем входы и отвергаем длину их векторного произведения `≤ 1e-6`: тогда порог зависит от угла, а не от длин входов.

## Задание

Реализуйте `buildOrthonormalBasis(a, b)` в [task.ts](../../../../exercises/09-build-orthonormal-basis/task.ts), возвращая `{ x, y, z }` — новые объекты `Vector3`. Можно использовать операции Three.js. Выбрасывайте `RangeError` для нулевого входа и при длине векторного произведения нормализованных входов `≤ 1e-6`. Не изменяйте входы.

Объясните, почему одной нормализации `a` и `b` недостаточно, чтобы сделать их ортогональными.

Запустите из корня репозитория:

```bash
npm test -- exercises/09-build-orthonormal-basis
```

## Visualization

Меняйте угол вектора `b` и наклон плоскости обоих входов. Голубая и золотая стрелки показывают исходные векторы; красная, зелёная и синяя — единичный базис. Панель показывает компоненты, длины и попарные скалярные произведения (их разберём в уроке 11; ноль означает перпендикулярность). Для параллельных входов демка сообщает, что базис построить нельзя.

Запустите из корня репозитория:

```bash
npm run demo -- exercises/09-build-orthonormal-basis
```
