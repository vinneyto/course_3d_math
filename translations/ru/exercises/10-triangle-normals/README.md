# 10. Нормали треугольника по вершинам

**Нормаль** — вектор, перпендикулярный поверхности. У плоского треугольника она перпендикулярна его плоскости. Нормали описывают ориентацию поверхности и нужны для освещения и определения того, с какой стороны мы смотрим на поверхность. **Единичная нормаль** имеет длину `1`.

Вершина — это точка, положение в пространстве. Разность положений двух вершин даёт вектор ребра. Здесь мы впервые используем точки на практике; подробнее отличие точек от векторов рассмотрим в уроке 21.

Для вершин `A, B, C`, перечисленных в нужном порядке обхода:

```text
edge1 = B − A
edge2 = C − A
areaVector = edge1 × edge2
normal = normalize(areaVector)
triangleArea = |areaVector| / 2
```

Рёбра не обязаны быть перпендикулярными. Оба вектора должны начинаться в одной вершине. Если сдвинуть все вершины на одинаковую величину, векторы рёбер и нормаль не изменятся.

Для `A = (0, 0, 0)`, `B = (2, 0, 0)`, `C = (1, 2, 0)` нормаль равна `(0, 0, 1)`, площадь — `2`. Если смотреть со стороны конца этой нормали на треугольник, обход `A → B → C` идёт против часовой стрелки. Перестановка `B` и `C` меняет обход и разворачивает нормаль. Обход выбирает одно из двух направлений нормали, но сам по себе не определяет, где физически находится «наружная» сторона произвольной модели.

Коллинеарные или совпадающие вершины образуют **вырожденный треугольник**: его площадь равна нулю, единичная нормаль не определена. В упражнении отвергаем длину вектора площади `≤ 1e-6` — это абсолютный порог в квадратных единицах координат.

Мы вычисляем **нормаль грани**. Для плавного затенения часто используют нормали вершин, усреднённые по соседним граням; на острых рёбрах они могут намеренно различаться. Сглаженные нормали вершин здесь не вычисляем.

## Visualization

Переключайте **A → B → C / A → C → B** и меняйте высоту треугольника, включая ноль. Полупрозрачный треугольник, стрелки рёбер и нормаль показывают смену обхода. Для удобства нормаль начинается в центре треугольника: перенос начала не меняет её направление. Панель показывает координаты вершин, компоненты рёбер, площадь и нормаль.
