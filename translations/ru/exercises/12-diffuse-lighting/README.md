# 12. Диффузное освещение через скалярное произведение

Матовая поверхность получает наиболее прямой свет, когда обращена к источнику. При скользящем угле тот же пучок распределяется по большей площади. **Закон косинусов Ламберта** описывает это с помощью нормали из урока 10 и скалярного произведения из урока 11.

В точке поверхности возьмём единичную наружную нормаль `N` и единичный вектор `L`, направленный **от поверхности к источнику света**. Оба вектора должны быть выражены в одной системе координат.

```text
intensity = max(0, N · L)
```

Это безразмерный коэффициент диффузного освещения от `0` до `1`, а не полный цвет пикселя. Простой рендерер умножает его на цвет поверхности и силу света. В этом упражнении не учитываем фоновый свет, тени и ослабление с расстоянием.

- `N` и `L` совпадают: интенсивность `1`.
- Они перпендикулярны: интенсивность `0`.
- Источник за поверхностью: отрицательное скалярное произведение ограничиваем нулём.

Нормализация важна: увеличение длины входной стрелки не должно делать поверхность ярче. Направления на камеру в этой диффузной модели нет. Перемещение камеры или совмещение её с источником **не гарантирует** максимум: всё ещё важна нормаль. Зеркальные блики — отдельная тема, в которой учитывается и направление на камеру.

## Задание

Реализуйте `diffuseIntensity(normal, toLight)` в [task.ts](../../../../exercises/12-diffuse-lighting/task.ts). Нормализуйте копии входов, вычислите скалярное произведение и ограничьте его снизу нулём. Не изменяйте входы. Для нулевого входного вектора выбрасывайте `RangeError`: из него нельзя получить направление.

```bash
npm test -- exercises/12-diffuse-lighting
```

## Visualization

Меняйте угол направления на свет от 0° до 180° относительно нормали. Независимо вращайте камеру: при движении только камеры яркость поверхности сохраняется. Подписанная поверхность показывает точный диффузный коэффициент оттенком серого; стрелки освещены обычным светом песочницы. Поверхность намеренно не использует эти источники, чтобы фоновый свет не менял результат формулы.

Запустите из корня репозитория:

```bash
npm run demo -- exercises/12-diffuse-lighting
```
