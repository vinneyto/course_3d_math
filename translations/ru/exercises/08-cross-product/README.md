# 8. Векторное произведение

**Векторное произведение** двух трёхмерных векторов — ещё один вектор:

```text
a × b = (ay*bz − az*by, az*bx − ax*bz, ax*by − ay*bx)
```

Если исходные векторы ненулевые и непараллельные, результат перпендикулярен плоскости, которую они задают, а значит, и обоим векторам. **Ортогональный** здесь означает **перпендикулярный**. Сами исходные векторы не обязаны быть перпендикулярными.

Длина результата равна **площади параллелограмма**, построенного на `a` и `b`:

```text
|a × b| = |a| |b| sin(θ),     0° ≤ θ ≤ 180°
```

Например, `(2, 0, 0) × (1, 2, 0) = (0, 0, 4)`. Угол не равен 90°, но площадь равна `основание × высота = 2 × 2 = 4`. Параллелограмм — плоский четырёхугольник; параллелепипед — объёмная фигура, для которой нужны три направления рёбер.

Операция **некоммутативна**, а точнее — **антикоммутативна**:

```text
b × a = −(a × b)
```

Направление задаёт правило правой руки: согните пальцы правой руки от первого вектора ко второму по меньшему углу; большой палец укажет направление результата. Для стандартного базиса `X × Y = Z`, а `Y × X = −Z`.

Для параллельных векторов, включая противоположно направленные и векторы разной длины, результат — **нулевой вектор**: `(2, 0, 0) × (5, 0, 0) = (0, 0, 0)`. Параллелограмм схлопывается в линию. Нулевой входной вектор тоже даёт ноль. У нулевого вектора нет направления: нормализацией из него нельзя получить единичную нормаль.

## Задание

Реализуйте `crossProduct(a, b)` в [task.ts](../../../../exercises/08-cross-product/task.ts) по компонентной формуле, без `cross()` и `crossVectors()`. Верните новый `Vector3`, не изменяя входные векторы. Обработайте параллельные, противоположные и нулевые векторы.

До запуска тестов предскажите результат `(1, 2, 3) × (0, 1, 0)`.

Запустите из корня репозитория:

```bash
npm test -- exercises/08-cross-product
```

## Visualization

Меняйте угол и длины двух векторов. Переключайте **a × b / b × a**: результат меняет направление, а полупрозрачный параллелограмм сохраняет площадь. Попробуйте 0° и 180° при разных длинах: стрелка результата исчезнет, потому что его длина равна нулю. Панель показывает компоненты, угол, длины и площадь. Масштаб всех стрелок одинаков.

Запустите из корня репозитория:

```bash
npm run demo -- exercises/08-cross-product
```
