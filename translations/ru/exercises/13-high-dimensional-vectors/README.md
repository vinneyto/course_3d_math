# 13. Многомерные векторы и сходство

У вектора не обязательно две или три компоненты. Массив из `n` чисел — **n-мерный вектор**. Его координаты не обязаны обозначать физические положения X, Y и Z.

Скалярное произведение естественно обобщается на любую положительную размерность:

```text
a · b = Σ ai*bi                 (сумма произведений соответствующих компонент)
|a| = sqrt(Σ ai*ai)
cosineSimilarity(a, b) = (a · b) / (|a| |b|)
```

Размерности должны совпадать. Результат по-прежнему скаляр, операция по-прежнему коммутативна. Косинусное сходство не определено, если хотя бы один вектор нулевой. Для ненулевых входов `+1` означает одинаковые направления, `−1` — противоположные; оба случая коллинеарны. При поиске похожих объектов обычно нужно высокое **положительное** сходство, а не просто коллинеарность.

В машинном обучении **эмбеддинг** (латентное представление) — вектор признаков, полученный обученной моделью. Например, модель может превращать каждое изображение лица в сотни чисел так, чтобы изображения одного человека обычно имели похожие представления. Признаки выучены моделью: отдельные компоненты обычно не имеют простых названий вроде «длина носа».

Один из вариантов распознавания — сравнить представление нового изображения с сохранёнными по косинусному сходству. На результат влияют освещение, ракурс, обучающие данные и выбранный порог. Высокий балл — свидетельство сходства, **не вероятность и не доказательство личности**. Реальные системы требуют проверки; здесь общий учебный пример, а не описание устройства Apple Face ID.

## Задание

Реализуйте `dotProductND(a, b)` и `cosineSimilarity(a, b)` в [task.ts](../../../../exercises/13-high-dimensional-vectors/task.ts) через циклы или операции над массивами, без Three.js. Входы — readonly-массивы конечных чисел одинаковой ненулевой длины. Для пустых массивов, разных длин и нечисловых/бесконечных компонент выбрасывайте `RangeError`. Функция `cosineSimilarity` дополнительно отвергает нулевые векторы. Не изменяйте массивы. В тестах используются умеренные величины; обработка переполнения чисел вне рамок упражнения.

Проверьте, что умножение представления на положительный скаляр меняет обычное скалярное произведение, но не косинусное сходство. Что происходит при отрицательном множителе?

Запустите из корня репозитория:

```bash
npm test -- exercises/13-high-dimensional-vectors
```
