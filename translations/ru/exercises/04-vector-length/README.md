# 4. Длина вектора

Длина вектора вычисляется по теореме Пифагора:

```text
|v| = sqrt(x² + y² + z²)
```

Для вектора `(3, 4, 12)`:

```text
|v| = sqrt(3² + 4² + 12²) = 13
```

В Three.js готовое вычисление выполняет `Vector3.length()`.
